# 📊 제네시스 투자 성과 리뷰 워크플로우

사용자가 **"제네시스 하자"** 라고 하면 아래 프로세스를 시작합니다.

## 1. 기준 리포트 탐색 (Source Report Discovery)

브라우저로 `https://genesis-report.com/picks` 에 접속하여 리포트 목록을 확인합니다.

> **⚠️ 상세 기록 위치 (v3):** 공개 페이지(`content/picks/`)는 대중용 요약만 담는다. 복기에 필요한 종목별 가격·목표가·손절가·룰·추적 명단은 비공개 상세 기록에서 읽는다.
>
> | 구분 | 상세 기록 | 그 이전 |
> | :--- | :--- | :--- |
> | 단기 | `content/picks-log/YYYYMMDD-genesis-log.mdx` (2026-10-07~) | `content/picks/` 본문 |
> | 중기 | `content/picks-log/YYYYMMDD-genesis-mid-log.mdx` (2026-10-08 개편 이후) | `content/picks/*-genesis-mid-report.mdx` 본문 |
> | 장기 | `content/picks-log/YYYYMMDD-genesis-long-log.mdx` (2026-10-08 개편 이후) | `content/picks/*-genesis-long-report.mdx` 본문 |
> | 성과리뷰 자신 | `content/review-log/YYYY-MM-DD-review-log.mdx` (2026-10-08~) | `content/picks-feedback/` 본문 |
>
> v3 상세 기록에는 프론트매터 `picks:` 목록이 있어 `scripts/review_scoreboard.py --log`로 바로 성적을 계산한다(4-1).

### 🎯 핵심 원칙
웹사이트의 유망 종목은 **단기 / 중기 / 장기** 3가지로 구분되어 있으며, 각 예측 기간이 다르므로 **기간에 맞는 시점에 복기**해야 합니다.

| 구분 | 예측 기간 | 복기 기준 시점 |
|---|---|---|
| 🚀 단기 | ~7일 이내 | 작업 당일 기준 **T-7** 리포트 |
| 📈 중기 | 3~6개월 | 작업 당일 기준 **T-30** 리포트 |
| 🧘 장기 | 1~3년 | 작업 당일 기준 **T-90** 리포트 |

### 🔍 탐색 순서

1. `https://genesis-report.com/picks` 에서 리포트 목록 전체를 확인합니다.
2. 각 리포트의 **종목 구분(단기/중기/장기)** 을 식별합니다.
3. 아래 순서로 복기 대상을 선별합니다.
   - **단기 복기**: 작업 당일 기준 약 7일 전에 작성된 **단기 유망 종목** 리포트를 탐색합니다. 단기 종목은 7일간의 예측이므로, 반드시 7일 안팎의 리포트여야만 의미 있는 복기가 됩니다.
   - **중기 복기**: 작업 당일 기준 약 30일 전에 작성된 **중기 유망 종목** 리포트를 탐색합니다.
   - **장기 복기**: 작업 당일 기준 약 90일 전에 작성된 **장기 유망 종목** 리포트를 탐색합니다.
4. 해당 기간의 리포트가 없으면 **해당 구분의 복기를 생략**합니다. (예: 90일 전 장기 리포트가 없으면 장기 복기 없이 단기·중기만 진행)
5. 복기 대상이 하나 이상 확인되면 다음 단계로 진행합니다.

> ⚠️ **주의**: 단기 유망 종목을 30일이나 90일 후에 복기하는 것은 의미가 없습니다. 예측 기간을 벗어난 종목은 복기 대상에서 제외합니다.

## 2. 현재 주가 수집 (Real-time Price Fetching)

> 💡 **`market-data-miner-skill` 활성화** — 이 단계에서 데이터 수집 및 Failover 처리를 담당합니다.

기준 리포트에서 추천 종목 목록(ticker, 추천가)을 추출한 뒤 아래 우선순위로 현재가를 수집합니다.

- **Priority 1: 네이버 증권** (`finance.naver.com/item/main.naver?code=XXXXXX`): 현재가, 등락률, 수급 데이터
- **Priority 2: 토스증권**: 네이버 접근 불가 시 대체
- **미국 주식**: 구글 파이낸스에서 현재가 및 USD/KRW 환율 반영
- **Failover**: 스크래핑 차단 시 차트 캡처 후 Vision 분석으로 수치 역산

## 3. 성과 계산 및 분석 (Performance Analysis)

> 💡 **`genesis-analyst-skill` 활성화** — 이 단계부터 스킬의 4가지 분석 모듈이 순서대로 실행됩니다.

각 종목에 대해 아래 지표를 산출합니다.

| 항목 | 계산 방법 |
|---|---|
| 수익률 | `(현재가 - 추천가) / 추천가 × 100` |
| 상태 | WIN(+5% 초과) / HOLD / LOSS(-5% 이하) / EXIT(손절가 이탈) |
| 손절 여부 | 추천 보고서의 손절가 기준으로 판정 |

스킬의 4가지 분석 모듈을 순서대로 실행합니다.

- **[Module 1] 기술적 성과 복기 (Technical Audit)**: 추천 당시 차트 위치 vs 현재 위치, 매수 타점의 적절성, 지지·저항선 작동 여부 판독
- **[Module 2] 논리 유효성 검증 (Logical Validation)**: 추천 Catalyst가 실제 시세 분출의 원인이었는지 대조, 외부 변수 개입 여부 확인, 진입 타이밍의 '시차' 분석
- **[Module 3] 패턴 추출 (Pattern Recognition)**: 반복되는 실수 또는 고승률 패턴 추출, 황원장님 투자 스타일의 강·약점 데이터화
- **[Module 4] 액션 플랜 제안 (Future Action Plan)**: WIN → Trailing Stop 또는 비중 확대 / LOSS → 손절의 적절성 평가 및 진입 금지 패턴 등록 / HOLD → 기회비용 대비 교체 매매 여부 판단

## 4. 보고서 생성 — 공개 성적표 + 비공개 상세 기록 (v3.0, 2026-10-08 대중형 개편)

단기 신호등·종목분석 v2·중기/장기 v3와 같은 방식이다. **공개 페이지는 누구나 읽는 쉬운 '성적표'**, 트랙·[R-xx] 룰·회귀·감시 순위·복리 엔진 통계는 비공개 상세 기록에 남긴다.

| 파일 | 내용 | 사이트 노출 |
| :--- | :--- | :--- |
| `content/picks-feedback/YYYY-MM-DD-performance-review.mdx` | **제네시스 성적표** — 쉬운 공개 페이지 (4-3) | ✅ |
| `content/review-log/YYYY-MM-DD-review-log.mdx` | **상세 기록** — 기존 v2 SOP 형식 전체 (4-2) | ❌ (contentlayer 대상 아님) |

> **⚠️ 전날 상태(트랙 회차·[R-xx] 룰·감시 순위·[R-53] ② 일일 판정 표·복리 엔진 누적 통계·다음 회차 확인 항목)는 가장 최근 `content/review-log/` 파일에서 읽는다.** 2026-10-07 이전 기록은 `content/picks-feedback/` 본문에 있다.
> 단기·중기 워크플로우가 "판정 기록처는 성과리뷰"라고 적은 항목도 이제 `content/review-log/`가 기록처다.
> **상세 기록을 먼저 쓰고, 그 숫자로 공개 페이지를 쓴다.** 공개 페이지에 새 수치를 만들지 않는다.

### 4-1. 성적표 계산 (필수)

```bash
# 단기 T-7 (지난주 같은 요일 단기 상세 기록)
python -X utf8 scripts/review_scoreboard.py --log content/picks-log/YYYYMMDD-genesis-log.mdx --json <scratchpad>/review.json
# 매달 1일: 중기 T-30 · 장기 T-90 상세 기록도 같이 (--log 여러 번)
python -X utf8 scripts/review_scoreboard.py --log content/picks-log/YYYYMMDD-genesis-log.mdx --log content/picks-log/YYYYMMDD-genesis-mid-log.mdx --log content/picks-log/YYYYMMDD-genesis-long-log.mdx
# picks: 가 없는 옛 리포트(2026-10-08 이전) — 리포트 본문 가격 전략에서 직접
python -X utf8 scripts/review_scoreboard.py --pick 011200:HMM:2026-09-30:21250:22850:20369:관심
```
- 판정은 모두 **종가 기준**: 🎯 목표가 도달 · 🛑 기준선 이탈(먼저 온 것) · 📈/📉 진행 중. 같은 기간 코스피 수익률을 나란히 낸다.
- `--public`: 공개 페이지용 — `kind: "섀도"`(조건 미달로 담지 않은 후보) 행을 뺀다. 섀도·트랙 B는 상세 기록에만.
- 이 출력이 공개·상세 두 파일의 **유일한 수익률 숫자**다. 손으로 다시 계산하지 않는다.

### 4-2. 상세 기록 — `content/review-log/YYYY-MM-DD-review-log.mdx`

v2 SOP 형식을 그대로 유지한다(프론트매터 포함).

```yaml
---
title: "YYYY-MM-DD 제네시스 성과 분석 리포트"
date: "YYYY-MM-DD"
summary: "상세 요약 (내부 용어 허용)"
tags: ["성과분석", ...]
---
```

1. **[Executive Summary]**: 4-1 성적표 표 + 종목별 수익률 · 평균 · 승률 · MDD (Module 1)
2. **[Logic Breakdown]**: 추천 당시 논리 vs 실제 움직임 (Module 2)
3. **[Critical Feedback]**: 가장 잘된 점 1 · 가장 아쉬운 점 1 · 감시 순위 (Module 3)
4. **[Compounding Insight]**: 다음에 반드시 적용할 룰 — [R-xx] 등록·발동·표본은 여기에만 (Module 4)
5. **[우팀장의 피드백]**
6. **[복리 엔진] 누적 통계**: 트랙별 누적 승률·평균·MDD, [R-53] ② 중기·장기 일일 판정 표
7. **다음 회차 확인 항목**

### 4-3. 공개 페이지 — `content/picks-feedback/YYYY-MM-DD-performance-review.mdx` (스마트폰 3~4화면 이내)

**작성 원칙**
- 내부 용어 금지: `[R-xx]`, 트랙 A/B, 회차, 섀도, 게이트, R:R, 명목/실질, 표본, 회귀, 카운터, 편출 등. 쉬운 말로.
  - 예: "[R-64] 발동·편출" → "열흘 안에 세 번 위험 기준선 아래로 마감해 관심 종목에서 뺐습니다", "트랙 A 35회차 공백" → "35거래일째 새 추천을 쉬고 있습니다"
- **정직 원칙:** 손실 종목을 빼거나, 좋은 기간만 고르거나, "관심 종목"의 성적을 "추천" 성적처럼 쓰지 않는다. 추천 0종목이면 그렇게 쓴다. 신뢰가 이 페이지의 유일한 자산이다.
- 권유 표현 금지("지금 사세요/파세요"). 숫자는 한국식 단위, 소수점 한 자리. MDX 부등호 금지.

**섹션 순서 (고정)**

```
# M월 D일 제네시스 성적표
> 한 줄 요약: (지난주 결과 한 문장 — 평균 vs 코스피)

## 📋 지난주(M/D) 종목, 어떻게 됐나요?
  - 4-1 단기 표 (--public) + 평균/코스피 비교 한 줄 (스크립트 출력 그대로)
  - 쉬운 해설 2~3개: 왜 올랐나/내렸나 (Module 2를 쉬운 말로)
  - 추천 0종목이면: "지난주에는 새 추천이 없었습니다(이유 한 줄)" + 관심 종목 성적만, '관심'임을 표시

(매달 1일만)
## 📈 한 달 전 중기 종목은? / ## 🧘 석 달 전 장기 종목은?
  - 4-1 중기·장기 표 + 한 줄. 해당 리포트가 없으면 섹션 생략

## 🚨 지켜보던 종목 알림
  - 오늘 중기·장기 추적 종목 중 위험 기준선 아래로 마감 / 목표가 도달 / 관심 종목에서 뺀 종목만, 쉬운 말 1줄씩
  - 없으면 "오늘은 특별한 변화가 없습니다" 한 줄

## ✅ 잘한 점 · 🤔 아쉬운 점      ← 각 1개, 2~3문장 (Module 3를 쉬운 말로)
## 📌 이번에 배운 것             ← "다음부터는 이렇게 합니다" 1개 (Module 4를 쉬운 말로, 룰 번호 없이)
## 📊 지금까지의 성적             ← 상세 기록 복리 엔진의 누적 수치를 쉬운 표로 (기간 · 종목 수 · 오른 비율 · 평균 · 같은 기간 코스피)
## ❓ 자주 묻는 질문              ← 2~3개 ("제네시스 추천 수익률", "손절은 언제 하나요" 같은 검색형). Q와 답 사이 빈 줄 필수
## 🔗 함께 보면 좋은 글            ← 오늘 신호등(/picks/YYYYMMDD-genesis-report) · 복기한 원래 리포트 · 교육글 (존재하는 slug만)
> 면책 조항 (단기 신호등과 같은 문구 + "과거 성과가 미래 수익을 보장하지 않습니다")
```

## 6. 복리 엔진 업데이트 (Compounding Engine)
