# 제네시스 모의 포트폴리오 일일 성과 리포트

> **2026-11-01 개편 (황원장 지시):** T-7·T-30·T-90 추천 복기를 끝내고, 매일 보유 종목 등락과 차트 신호를 게시한다.
> 구 시스템 최종 성적은 `public/charts/portfolio/legacy.json`으로 마감했다. 이전 절차는 git 기록에서 볼 수 있다.

## 1. 실행 시각

장 마감 후 20:40 이후. "제네시스 하자"의 마지막 단계 또는 "투자성과리뷰 제네시스하자"로 실행한다.

## 2. 절차

### Step 1. 시작일에만: 시가 기록

월 시작일 장 시작 후 한 번 실행한다. 포트폴리오 JSON과 시작 명단 파일에 시가가 기록된다.

```bash
python -X utf8 scripts/portfolio_review.py --set-open
```

### Step 2. 점검 결과 확인

`scripts/portfolio_check.py`에서 확정된 변경이 있으면 먼저 `public/charts/portfolio/events.json`에 기록한다. 리포트의 "오늘 변경 사항"에 자동으로 실린다.

### Step 3. 리포트 생성

```bash
python -X utf8 scripts/portfolio_review.py --write
python -X utf8 scripts/check-structure.py
```

- 숫자와 차트 신호는 스크립트 값을 그대로 쓴다. 고치지 않는다.
- 기준일 시세가 없으면 스크립트가 멈춘다. 휴장일이면 게시하지 않는다.
- 차트 신호는 참고 표시다. 달 중간 매매 표현을 쓰지 않는다.

### Step 4. Push + SNS

콘솔의 `[차트 JSON]` 파일을 함께 올린다. 커밋 해시를 확인한 뒤 SNS에 올린다.

```bash
python -X utf8 scripts/push_report.py content/picks-feedback/YYYY-MM-DD-performance-review.mdx "feat: YYYY-MM-DD 투자 성과 리포트" public/charts/stock/YYYY-MM-DD-294400.json ...
python -X utf8 scripts/post_threads.py content/picks-feedback/YYYY-MM-DD-performance-review.mdx
python -X utf8 scripts/post_linkedin.py content/picks-feedback/YYYY-MM-DD-performance-review.mdx
```

시가를 기록한 날은 `public/charts/portfolio/YYYY-MM.json`과 `content/portfolio-log/YYYY-MM-start.mdx`도 함께 올린다.

### Step 5. 완료 보고

커밋 해시, 파일 경로, SNS 게시 결과를 보고한다.
