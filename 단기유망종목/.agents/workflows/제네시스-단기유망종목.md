# 🚀 AntiGravity 단기 유망 종목 발굴 워크플로우 (제네시스)

사용자가 **"제네시스 하자"** 라고 요청하면 즉시 아래 4단계를 순서대로 실행한다.

> **데이터 수집 방법**: `naver-data-fetcher` 스킬의 Python 코드를 Bash로 실행.
> 로컬 PC(한국 IP)에서 직접 네이버 증권에 접근하므로 차단 없음.
> Python 실행 불가 시 스킬 내 Failover 절차를 따른다.

---

## Step 1. 시장 환경 점검 → 공격/중립/방어 판단

### 1-1. KOSPI / KOSDAQ 지수 수집

`naver-data-fetcher` 스킬 **[Function 1]** 실행 후 아래 표를 채운다.

| 지표 | 수치 | 등락 | 거래대금 |
| :--- | :--- | :--- | :--- |
| KOSPI | | | |
| KOSDAQ | | | |
| USD/KRW | | | WebSearch: `달러 원화 환율 오늘` |

### 1-2. 수급 주체 파악

WebSearch 실행: `코스피 코스닥 {오늘날짜} 마감 시황 외국인 기관 순매수`

- 외국인: 순매수 / 순매도 / 혼조
- 기관: 순매수 / 순매도 / 혼조

> **⚠️ 당일 데이터 사용 규칙:** 네이버 증권 투자자별 순매매 페이지는 좌(전날)·우(당일) 두 컬럼이 표시된다.
> 반드시 **우측 당일 날짜** 컬럼 데이터만 사용한다.
> Python 수집 시: `re.findall` 전체 결과 후반부 `all_items[len(all_items)//2:]`가 당일 데이터.

### 1-3. 시장 판단 결론 (필수 명시 후 Step 2 진행)

| 판단 | 조건 | 액션 |
| :--- | :--- | :--- |
| **공격** | 외인+기관 쌍끌이, 거래대금 20조↑ | 종목 3개 발굴 |
| **중립** | 수급 혼조, 거래대금 보통 | 종목 3개 발굴 (비중 축소 권고) |
| **방어** | 외인+기관 쌍매도, 지수 하락압력 | 종목 2개로 축소, 리스크 가이드 강화 |

> **결론: [ 공격 / 중립 / 방어 ]** ← 반드시 하나 선택 후 기재

### 1-4. ⚠️ 변동성 상한 필터 — 시장 판단 최종 확정 (2026-07-30 신규)

> **등록 배경:** 2026-07-23 리포트는 코스피 3일 반등(+4.40%)만 보고 **'공격'** 을 선택했다.
> 당시 3종목 평균 ATR/주가는 **9.40%** 였고, 이후 5거래일간 코스피는 **-21.18%** 하락했다.
> 지수 등락률·수급만 보고 국면을 판단하면 **변동성이라는 세 번째 축**을 놓친다.

Step 2-2에서 산출한 **최종 선정 종목의 평균 ATR/주가**로 1-3의 판단을 재검증한다.

| 평균 ATR ÷ 주가 | **허용되는 시장 판단** | 총 비중 상한 |
| :--- | :--- | :--- |
| **3% 이하** | 공격 / 중립 / 방어 | 30% |
| **3% 초과 ~ 5% 이하** | **중립 / 방어만** (공격 금지) | 15% |
| **5% 초과** | **방어만** | **7.5% 이하 또는 발간 보류** |

- 1-3의 판단이 이 상한을 초과하면 **상한에 맞춰 하향 조정**하고, 그 사유를 리포트 섹션 1에 명시한다.
- 총 비중 상한은 섹션 3 리스크 가이드에 그대로 반영한다.

## Step 2. 종목 스크리닝 (수급 + 기술적 타점)

### 2-1. 수급 스크리닝 — 후보군 추출

**① 외국인 순매수 상위** → `naver-data-fetcher` 스킬 **[Function 2]** 실행

- KOSPI 상위 10종목 목록 기록
- KOSDAQ 상위 10종목 목록 기록

**② 기관 순매수 상위** → `naver-data-fetcher` 스킬 **[Function 3]** 실행

- KOSPI 상위 10종목 목록 기록
- **외국인 리스트와 겹치는 종목 → 최우선 후보 지정**

> **⚠️ "쌍끌이" 판정 규칙 (반드시 준수)**
> ①외국인 리스트와 ②기관 리스트를 나란히 놓고 **두 리스트에 동시에 이름이 있는 종목만** "쌍끌이"로 부른다.
> - 기관 리스트에만 있는 종목 = **"기관 독주"** (외국인은 매도 중일 수 있음)
> - 외국인 리스트에만 있는 종목 = **"외국인 주도"**
> - 확인이 필요하면 `python scripts/naver_finance.py investor [종목코드]`로 당일 외국인·기관 수치를 직접 조회한다.

**③ 거래량 급증 종목** → `naver-data-fetcher` 스킬 **[Function 4]** 실행

- 전일 대비 거래량 2배 이상 + 상승 마감 종목만 추출

**④ 주도 테마 확인** → WebSearch: `오늘 상승 주도 테마 섹터 종목`

- 당일 상승률 상위 테마 1~2개 식별, 해당 테마 내 후보 추가

> 위 ①②③④를 종합하여 **후보군 5~7종목** 압축

### 2-1-B. ⚠️ [룰 R-05] 쌍끌이 비중 제한 (2026-07-31 신규)

> **등록 배경:** 2026-07-24 방어형 3종목 복기 결과, **쌍끌이가 확인된 종목만 살아남았다.**
> | 종목 | 수급 구조 | MDD | 결과 |
> | :--- | :--- | ---: | :--- |
> | 셀트리온 | **쌍끌이**(외 +206억/기 +294억) | **-1.01%** | **WIN +5.12%** |
> | SK텔레콤 | 기관 단독(+988억) | -24.00% | 손절 -4.50% |
> | 메리츠금융지주 | 기관 단독(+200억) | -6.33% | 손절 -4.30% |
>
> 같은 기간 코스피는 -16.40% 하락했다. **기관 순매수 금액은 판별력이 없었다** — 최대 금액 종목(SK텔레콤 +988억)이 최악의 결과였다.

| 수급 구조 | 부여 비중 |
| :--- | :--- |
| **쌍끌이** (외국인·기관 순매수 상위 **동시 등장**) | **정상 비중 (1)** |
| 기관 단독 / 외국인 단독 | **비중 1/2** |

- **최종 3종목 중 최소 1종목은 반드시 쌍끌이 종목으로 채운다.**
- 쌍끌이 종목을 하나도 확보하지 못하면 그 사유를 리포트 섹션 1에 명시하고 **총 비중을 추가로 절반 축소**한다.
- 비중 배분 결과는 섹션 3 리스크 가이드에 종목별로 표기한다.

### 2-2. ⚠️ ATR(14) 선계산 및 등급 판정 (기술적 타점보다 **먼저** 실행)

> **2026-07-30 절차 변경.** ATR 계산이 항상 마지막이라 4주 연속 미이행됐다.
> **이 단계를 통과하지 않으면 2-3으로 넘어갈 수 없다.**

후보 종목별 ATR(14, Wilder)을 계산하고 아래 등급을 판정한다.

```
ATR(14) = 최근 14거래일 True Range의 Wilder 평활 평균
True Range = max(고가-저가, |고가-전일종가|, |저가-전일종가|)
```

| ATR(14) ÷ 주가 | 종목 등급 | 조치 |
| :--- | :--- | :--- |
| **3% 이하** | 정상 | 정상 발간 |
| **3% 초과 ~ 5% 이하** | 주의 | 발간하되 **비중 절반**, 손절폭 ATR 1.5배 강제 |
| **5% 초과** | **발간 금지** | **후보에서 제외** |

**손절가 산정 규칙 (2-3에서 적용):**
```
손절가 = 기술적 지지선과 (현재가 - ATR×1.5) 중 더 넓은 쪽
```
→ 손절폭이 넓어지면 R:R이 자동으로 낮아지고 2:1 필터에서 걸러진다. **변동성 높은 국면에서 발간 종목 수가 줄어드는 것이 이 규칙의 의도된 결과다.**

> **⚠️ [2026-07-31 소급검증 결과] 이 규칙의 두 부분은 효과가 다르다.**
> 2026-07-24 3종목에 소급 적용한 결과:
> - **발간금지 필터(ATR 5% 초과 제외)는 유효했다.** 최대 손실 종목 SK텔레콤(ATR 6.37%)이 걸러지며 평균 수익률이 -1.22% → **+0.41%** 로 개선됐다.
> - **그러나 손절폭 확대(ATR×1.5)는 역효과였다.** 메리츠금융지주는 ATR 손절가(115,640원)를 실제 저가(115,500원)가 **140원 차이로 이탈**해 결국 손절됐고, 손실은 -4.30% → **-6.21%** 로 커졌다.
>
> **결론: ATR은 "무엇을 사지 말 것인가"에는 강력하나 "얼마나 버틸 것인가"에는 만능이 아니다.** 손절폭은 아래 R-06에 따라 종목 유형별로 판단한다.

### 2-2-B. [룰 R-06] 손절 사유 사후 구분 기록 (2026-07-31 신규)

손절이 발생하면 그 원인을 아래 두 가지로 **반드시 구분해 기록**한다. 이 데이터를 누적해 손절폭 정책을 종목 유형별로 분화한다.

| 구분 | 정의 | 유리한 손절폭 |
| :--- | :--- | :--- |
| **① 개별 악재** | 공시·실적 등 종목 고유 사유로 추세가 붕괴 | **좁은 손절** (기술적 지지선 기준) |
| **② 시장 변동성** | 지수 전체 하락에 동반된 흔들림, 이후 회복 | **넓은 손절** (ATR×1.5 기준) |

- 2026-07-24 사례 분류: SK텔레콤 = **①개별 악재**(대규모 출자 공시) / 메리츠금융지주 = **②시장 변동성**
- 다음 복기 시 이 분류를 누적하여, 표본이 쌓이면 종목 유형별 손절폭 규칙을 확정한다.

### 2-2-C. [룰 R-07] ATR 기반 손절 정책 이원화 (2026-08-03 신규 / 2026-08-04 적용조건 추가)

**2-2의 "손절가 = 기술적 지지선과 (현재가 - ATR×1.5) 중 더 넓은 쪽" 규칙을 아래로 대체한다.**

| ATR/주가 | 손절 정책 |
| :--- | :--- |
| **5.5% 이하** | **손절 유예** — 손절가는 **구조적 지지선(20일선·전저점)**으로 설정하고, 그 이탈 시에만 청산 |
| **5.5% 초과** | **손절 즉시 집행** (단, 아래 적용 조건 확인) |

> **등록 근거(2026-08-03 복기, 9종목):** ATR 5.41% 이하 3종목은 전부 손절이 손해(평균 -5.80%p), ATR 7.40% 이상 6종목은 전부 손절이 이득(평균 +16.31%p)이었다. 경계 구간에 겹치는 종목이 없었다.

### 2-2-D. ⚠️ [룰 R-09] 20일선 이격도 상한 (2026-08-04 신규)

**2-3 진입 전 반드시 이격도를 계산한다.** `이격도 = (현재가 ÷ 20일선 - 1) × 100`

| 20일선 이격도 | 조치 |
| :--- | :--- |
| **+7% 이하** | 정상 발간 |
| **+7% 초과 ~ +10% 이하** | **비중 1/2** — 눌림목 분할 진입만 허용 |
| **+10% 초과** | **발간 금지** — 후보에서 제외, 20일선 근접 시 재검토 |

> 하루 차이 표본에서 이격도가 12.93%p 차이 나고 MDD가 **13.49%p** 차이 났다. **R-09는 양방향으로 일관성이 확인된 첫 룰이다. 예외 없이 적용한다.**
> 또한 **"누적 11종목 예외 없이 8거래일 이내 고점" 패턴이 이 표본에서 처음 깨졌다** — 2종목 모두 기간 최고가가 T+5(복기 당일)였다. 이격이 낮으면 고점이 뒤로 밀린다.

### 2-2-E. ⚠️ [룰 R-10] 하락일 상대강도 예외 (2026-08-05 신규)

**지수가 -5% 이상 급락한 거래일에, 시가총액 상위 20종목 중 상승 마감한 종목은 ATR 등급·정배열 조건과 무관하게 후보 자격을 유지한다.**

| 조건 | 처리 |
| :--- | :--- |
| 지수 **-5% 이상 급락일** + 시총 상위 20위 내 + **상승 마감** | **ATR 발간금지·정배열 미충족이어도 후보 유지** |
| 단, 20일선 이격도 **[R-09]는 예외 없이 적용** | +10% 초과 시 여전히 제외 |
| 부여 비중 | **정상 비중의 1/2** (ATR 리스크 보정) |

> **등록 근거(2026-08-05 복기):** 2026-07-29는 코스피 **-5.98%**, 사상 첫 2거래일 연속 동반 서킷브레이커, 상승률 상위 1~18위가 전부 인버스 ETN이었던 날이다. 그날 시총 상위 20종목 중 상승 마감한 종목은 **셀트리온(+1.47%)·현대모비스(+1.14%) 단 2개**였고, 두 종목 모두 5거래일 뒤 **WIN**이었다.
>
> | 종목 | 추천시 ATR | ATR 등급 | 추천시 이격도 | 정배열 | **실제 결과** |
> | :--- | ---: | :--- | ---: | :---: | ---: |
> | 셀트리온 | 4.50% | 주의 | +2.46% | **✗** | **+5.72% WIN** |
> | 현대모비스 | **9.19%** | **발간금지** | -8.02% | **✗** | **+13.03% WIN** |
>
> **현행 필터를 그대로 적용하면 최고 수익 종목 현대모비스가 ATR 9.19%로 후보 단계에서 제외되고, 두 종목 모두 정배열 미충족으로 탈락한다.** 손절가는 둘 다 한 번도 터치되지 않았다(여유 4.1% / 2.5%).
>
> **핵심 논리:** 지수가 -5% 이상 빠지는 날 ATR은 **시장 전체가 만든 숫자이지 종목 고유의 위험이 아니다.** 그런 날 오르는 종목은 변동성에 노출됐을 뿐이며, 오히려 **그 노출을 이겨냈다는 증거**다. 하락일 상대강도는 ATR이 측정하지 못하는 정보를 담는다.
>
> **적용 한계:** 표본 2종목. 다음 급락일 사례에서 재검증하고, 반례가 나오면 즉시 하향 조정한다.
> **이 룰은 ATR 발간금지 필터의 첫 명확한 반례로 등록된 것이며, 필터 자체를 폐기하는 것이 아니다.** 평상시 ATR 필터는 그대로 유지한다.

### 2-3. 기술적 타점 검증 — 후보 종목 개별 확인

각 후보 종목별 `naver-data-fetcher` 스킬 **[Function 5]** 실행

```
종목명 (코드) 검증:
  - 현재가: ___원
  - ATR(14) / 주가: ___%  ← 2-2에서 산출, 등급 통과 종목만 진행
  - 최근 5일 흐름: 상승 / 하락 / 횡보
  - 이동평균선: 5일·20일·60일선 정배열 여부 → 정배열만 통과
  - 20일선 이격도: ___%  ← 2-2-D(R-09) 등급 판정. +10% 초과 시 즉시 제외
  - RSI 추정: 거래량 패턴으로 과열 여부 판단 (급등 연속 3일↑ = 제외)
  - 거래량 패턴: 음봉 감소 → 양봉 폭발 여부
```

> 수급 + ATR 등급 + **이격도 등급** + 기술적 조건 동시 충족 종목 **3~5개로 압축**

## Step 3. 리스크 필터링 및 공시 검증

후보 종목별 `naver-data-fetcher` 스킬 **[Function 6]** 실행 후 아래 체크

### 3-1. 즉시 제외 조건 — 하나라도 해당 시 탈락

- [ ] 최근 5거래일 내 **유상증자·전환사채(CB)·주식 담보대출** 공시
- [ ] **투자경고·투자위험 종목** 지정 이력
- [ ] 최대주주·임원의 **대량 지분 매도** 공시
- [ ] 거래소 **조회 공시 요구** 수신

### 3-2. 모멘텀 유효성 확인

- [ ] 상승 이유(테마·수급)가 **뉴스/공시로 뒷받침**되는가
      → 근거 없는 급등 = 세력 개입 가능성 → 제외
- [ ] 섹터 내 **대장주 지위**인가
      → 2~3등 종목보다 대장주 우선

### 3-3. 최종 3종목 확정

**R:R(수익/리스크 비율) 2:1 이상 종목만 선정**
- 예: 목표가 +10% / 손절가 -5% → R:R = 2:1 통과
- 예: 목표가 +8% / 손절가 -7% → R:R = 1.14 → 제외

> **최종 선정: 3종목 (방어 판단 시 2종목)**

### 3-4. ⚠️ 시장 단위 발간 게이트 (2026-08-03 등록 / 필수 최종 관문)

**종목 단위 필터를 모두 통과했더라도, 아래 3조건 중 하나라도 미달이면 발간을 보류하고 0종목으로 리포트를 낸다.**

| 조건 | 기준 |
| :--- | :--- |
| 시장 평균 ATR/주가 (시총 상위 전수조사) | **7% 이하** |
| 발간금지 등급(ATR 5% 초과) 비중 | **70% 이하** |
| 외국인 코스피 순매수 | **2거래일 연속 순매수** |

- 게이트 미달 시에도 **스크리닝 결과 전체와 각 조건의 현재 수치를 리포트에 그대로 기재**한다. 수치의 추이가 재개 시점을 판단하는 데이터가 된다.
- 종목 단위 필터를 전부 통과한 종목이 있으면 **"관찰 종목"으로 등재**하되, 발간 종목이 아님을 명시하고 가격 전략은 참고용으로만 표기한다.

## 🚦 운영 원칙

1. **스킬 우선 실행**: 데이터 수집은 반드시 `naver-data-fetcher` 스킬의 Python 코드를 Bash로 실행한다. 임의로 수치를 추정하거나 생략하지 않는다.
2. **데이터 무결성**: 수집한 수치는 소수점까지 그대로 기록한다. **네이버 증권 순매매 상위 페이지는 좌(전날)·우(당일) 두 컬럼 표시 → 반드시 우측(당일) 데이터만 사용. Python 시 `all_items[len(all_items)//2:]` 필수.**
3. **가격 정보 필수**: 모든 추천 종목에 **현재가·목표가·손절가**를 명시한다. R:R 2:1 미만 종목은 선정하지 않는다.
4. **시장 판단 우선**: Step 1의 공격/중립/방어 결론이 이후 모든 단계의 기준이다. 방어 판단 시 무리한 발굴을 하지 않는다.
5. **자동 푸시**: 리포트 저장 완료 후 `push.md`를 즉시 자동 실행한다.
