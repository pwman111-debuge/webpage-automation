# 🚀 제네시스(Genesis) v4.0 시황 분석 워크플로우

> **2026-10-06 개편 (황원장 지시)** — v3.5 시황이 너무 길고 전문적이라 가독성이 떨어졌다.
> v4.0은 ① **한눈에 보는 쉬운 시황**(지수 카드·수급 막대·업종·순위) ② **코스피·코스닥 차트 신호**(주도섹터 `차트 신호` 트리거 규칙으로 매수·매도 구간 박스 마킹 + 쉬운 말 해설) 두 축으로 간다.
> 숫자 나열·체크리스트 채점·11분류 수급 분석 같은 전문 분석은 **넣지 않는다**.

---

## 1. 실행 트리거

"제네시스 하자"(전체 순서의 첫 단계) 또는 "시황분석 제네시스하자" 입력 시 가동.

**실행 시각:** 장 마감 후 **20:40 이후** 권장. 외국인·기관 종목별 순매수 확정이 20:36 이후라 그 전엔 잠정치다(리포트에 자동으로 '잠정치' 문구가 붙는다).

## 2. 실행 절차

### [Step 1] 데이터 수집 + 차트 신호 + 초안 생성 (자동, 약 15초)

```bash
python -X utf8 scripts/market_brief.py --write
```

- 산출물
  - `content/market-analysis/YYYY-MM-DD-market-analysis-genesis.mdx` — 초안(이미 있으면 보존, 덮어쓰려면 `--force`)
  - `public/charts/market/YYYY-MM-DD-kospi.json` · `-kosdaq.json` — 차트 데이터(`<SignalChart>`가 읽음)
  - `%TEMP%/genesis_market_brief_YYYYMMDD.json` — 원자료(저장소 밖, 분석 참고용)
- 콘솔에 지수·수급·업종·**차트 신호 상태와 다음 방아쇠 조건**이 요약된다. 먼저 읽고 오늘 그림을 잡는다.
- `⚠️ 기준 거래일 ≠ 오늘`이 뜨면 휴장일/장 전이다 → 리포트 생성 중단하고 보고.

### [Step 2] 분석가가 채우는 부분 (Claude)

초안은 데이터로 완성돼 있다. Claude는 아래 **세 군데만** 손본다. 나머지 블록(지수 카드·수급·업종·순위·차트·신호 카드)은 숫자를 바꾸지 않는다.

1. **제목(title)** — 오늘 시장을 한 문장으로. 쉬운 말, 35자 안팎.
   예: `"반도체 팔고 2차전지 샀다 — 코스피 0.9% 하락, 코스닥 3% 급등"`
2. **summary** — 초안 3문장을 기반으로 2~3문장. 숫자는 초안 값 그대로.
3. **"## 오늘 왜 이렇게 움직였나"** — `{/* WRITE: ... */}` 주석 줄을 지우고 3~5문장 작성.
   - WebSearch로 **오늘 마감 시황 기사**를 찾아 원인(미국 증시·금리·환율·실적·정책 뉴스 등)을 확인한다.
   - 기사 원인과 초안 데이터(강한 업종·외국인 매수 종목)를 연결해 설명한다.
   - 확인 안 된 원인은 쓰지 않는다. 추측이면 "~로 보입니다"가 아니라 아예 뺀다.
4. (선택) **KeyPoints 3줄**을 더 매끄럽게 다듬어도 된다 — 숫자는 바꾸지 않는다.
5. (선택) **"## 8. 내일 볼 것"**에 뉴스 일정(미국 지표 발표·실적 발표 등) 1줄 추가 가능.

### [Step 3] 검증

```bash
python -X utf8 scripts/check-structure.py
```
- MDX 금지 패턴 확인: 본문 텍스트에 `<숫자`·`<한글` 금지(“미만/이하”로), 중괄호 `{ }`는 JSX 안에서만.
- `{/* WRITE` 주석이 남아 있지 않은지 확인.

### [Step 4] Push + SNS (자동, 승인 불필요)

```bash
python -X utf8 scripts/push_report.py content/market-analysis/YYYY-MM-DD-market-analysis-genesis.mdx "feat: YYYY-MM-DD 시황 분석 리포트" public/charts/market/YYYY-MM-DD-kospi.json public/charts/market/YYYY-MM-DD-kosdaq.json
python -X utf8 scripts/post_threads.py content/market-analysis/YYYY-MM-DD-market-analysis-genesis.mdx
python -X utf8 scripts/post_linkedin.py content/market-analysis/YYYY-MM-DD-market-analysis-genesis.mdx
```
**차트 JSON 두 개를 반드시 같이 push한다** — 빠지면 사이트 차트가 "불러오지 못했습니다"로 뜬다.
완료 후 커밋 해시, Threads Post ID, LinkedIn Post URN 보고.

## 4. 차트 신호 규칙 (주도섹터 `차트 신호` 트리거와 동일)

원본: `주도섹터/scripts/chart_signal.py`. `scripts/market_brief.py`에 같은 규칙·파라미터로 옮겼고 2026-10-06 코스피 20건·코스닥 19건 신호가 원본과 **완전 일치**함을 확인했다. **한쪽 규칙을 바꾸면 반드시 양쪽 같이 바꾼다.**

- **2단계 구조:** ①준비(arm) = 눌렸다/과열됐다 → 박스 시작 ②방아쇠(fire) = 방향이 꺾였다 → 박스 끝 + ▲▼
- **▲ 매수:** 종가 > 120일선 안에서 (%B 20 미만 또는 RSI7 35 미만) + 종가 < 20일선 → MACD 막대 음→양 + 20일선 회복. 단 120일선 이격 1년 백분위 92 이상이면 취소.
- **▼ 매도:** 120일선 이격 1년 백분위 80 이상 + (RSI7 70 초과 또는 %B 85 초과) → MACD 막대 양→음 + 20일선 이탈.
- 준비 유효기간 10거래일, 같은 방향 재발동 금지 10일.
- **상태 판정:** 최근 5거래일 안 방아쇠 → ▲매수 신호 / ▼매도 신호 · 준비 조건 → 매수 준비 / 과열 주의 · 그 외 → 신호 대기
- 데이터: KRX 정규장 지수 일봉 7년.

**해설 원칙 (반드시 지킨다):**
- 매도 신호는 **'팔아라'가 아니라 '여기서 더 사지 말자'**로 쓴다 (20년 검증 매도 적중은 동전 이하).
- 차트는 **'언제'**만 말한다. 무엇을 사라고 쓰지 않는다. 단독 매매 근거 아님.
- 과거 성적은 항상 **'아무 날이나 샀을 때'와 비교**해서 쓴다 (스크립트가 자동 표기).

## 5. 문체 가이드 (v4.0)

- **쉬운 말.** 한 문장에 한 가지 사실. 전문용어는 처음 나올 때 풀어 쓴다(예: "20일선(최근 한 달 평균 가격)").
- **존댓말 '~습니다'체**로 통일.
- 숫자는 꼭 필요한 것만. 블록이 보여 주는 숫자를 본문에서 다시 나열하지 않는다.
- **데이터 제공 사이트 이름을 쓰지 않는다** (출처 표기는 "한국거래소 시세·투자자별 매매동향").
- "쌍끌이"는 외국인·기관 순매수 상위 명단 **두 곳에 동시에** 있는 종목에만 쓴다.
- 본문 분량: 블록 제외 텍스트 **1,500자 안팎**. 길어지면 뺀다.
- 면책 문구(스크립트가 자동 삽입)는 지우지 않는다.
